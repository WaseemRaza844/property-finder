TRANSPARENCY, BUILT IN

Know where your data comes from.

No website scraping

Search links open the selected source in a new tab. They do not connect a feed. The status below describes only automated imports; a successful refresh does not mean these websites were searched.

How do I add listings?

Add a JSON export you have permission to publicly redistribute to imports/listings.json, then run the refresh workflow. Listing data and price history are public on GitHub Pages. Website search links do not provide an ingestion feed.
